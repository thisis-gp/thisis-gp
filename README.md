# D A Gurupriyan

Software engineer at Nova Benefits in Bangalore. I build AI retrieval systems, tools that let AI agents work safely with real data, and on-device AI apps.

## What I've built

- **[ctxd](https://github.com/thisis-gp/ctxd)**: a TypeScript MCP server that gives AI agents reviewed, read-only access to company data through Metabase. Published on npm and used at Nova Benefits.
- **[Kanoon](https://github.com/thisis-gp/kanoon)**: search and Q&A over 924 Indian Supreme Court judgments, using pgvector, BM25 and a cross-encoder reranker. It is the system behind my IEEE paper. [Live demo](https://kanoon-two.vercel.app/)
- **[NILA](https://github.com/thisis-gp/nila)**: an intent-first Android launcher that runs Gemma on the phone. I led a team of three.
- **[slimpdf](https://github.com/thisis-gp/slimpdf)**: a PDF compressor that hits a target file size. Published on [PyPI](https://pypi.org/project/slimpdf/) and used at Nova Benefits.
- **[Jimi](https://github.com/thisis-gp/jimi-android)**: an on-device voice listener for mental health, built at the iQOO Hackathon 2026. I led a team of three.
